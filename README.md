# 守屏（Shouping）

一款本地优先的 macOS 使用时间与专注管理应用。它通过多显示器全屏遮罩、应用白名单、定时规则和每日额度，帮助用户把电脑暂时留在重要任务上。

## 当前状态

已完成可安装的 `0.7.1` MVP：

- 快速专注：15、25、45 分钟，以及 1–720 分钟自定义。
- 可分别设置专注会话是否允许暂停 5 分钟、是否允许跳过。
- 可预设或随机生成退出密码；复制内容会包含生成时间和用途说明。
- 把密码交给保密人时，需连续完成三次发送确认才会采用。
- 移除退出密码前必须验证当前密码。
- 暂停时长支持秒、分钟和小时自定义。
- 可添加多个独立定时方案，每个方案单独设置时间、生效日和保护期。
- 定时方案支持自定义星期、中国大陆工作日和非工作日。
- 工作日历每年自动更新，包含法定假日和调休补班；离线时回退到周一至周五/周末。
- 保护期内会拦截 Finder、终端、活动监视器和系统设置等高风险管理入口。
- 可选择在 Finder 中隐藏应用；它仍通过登录项和后台助手自动启动。
- 屏保采用单一的黑底极简数字时钟，放大显示时:分，并显示小号日期和可选天气。
- 工作日或每日定时限制，支持跨午夜。
- 每日活跃使用额度。
- 连续使用与强制休息。
- 应用白名单和从专注屏直接启动允许应用。
- 多显示器覆盖窗口，支持不同 Space 和全屏应用场景。
- 菜单栏常驻、预览、临时解锁和提前结束。
- 本地前台应用统计，不采集窗口标题、屏幕画面和按键内容。
- 登录启动。
- 规则生效时由 LaunchAgent 恢复主应用。
- 强制模式、辅助功能与输入监控实测。

## 运行

本地构建：

```zsh
./Scripts/build_app.sh
./Scripts/package_dmg.sh
./Scripts/install_local.sh
```

构建产物：

- 应用：`build/守屏.app`
- 安装镜像：`build/守屏-0.7.1.dmg`
- 已安装版本：`/Applications/守屏系统组件/守屏.app`

应用以菜单栏图标启动；关闭设置窗口不会结束守屏。

### 启动与暂停

- 登录启动和后台恢复都已注册到 macOS，当前状态可在“规则 → 运行”中查看。
- 后台助手每 5 秒检查一次。重启并登录后，主应用会由登录项启动；若当前时段已经开始，后台助手也会恢复规则。
- 暂停 5 分钟会解除遮罩和键盘拦截，期间可以正常使用所有应用。
- 跳过会结束快速专注，或让当前定时、额度、休息限制失效到其自然结束。
- 暂停和跳过各自独立开关；关闭后对应按钮、菜单项和紧急快捷键均不可用。
- 未设置密码时，不会显示暂停或跳过入口；允许任一入口时会阻止启动新的快速专注并提示先设置密码。
- 开启后台恢复时，暂停不会结束当前专注承诺。主动退出会被拒绝；强制退出后，后台助手会在约 5 秒内重新拉起。
- 强制模式可用 `Control + Command + U` 临时解锁 5 分钟。
- Finder 隐藏只用于减少误删和随手移动；管理员仍能找到、停止或删除应用。
- 应用实际安装在隐藏目录 `/Applications/守屏系统组件/`，隐藏的是外层目录，不修改签名内的应用包内容。
- 提前保护只拦截常见系统管理入口；通过其他脚本工具、远程终端、管理员账户或恢复模式仍可绕过。
- 普通 Mac 应用无法可靠阻止管理员移动或删除应用、清空 Application Support、使用“强制退出”或恢复模式。这些属于系统级可见绕过，不能宣称“防破解”。


已验证 UI、快速专注、定时专注、自动恢复、白名单启动和后台恢复。详细记录见 [docs/TEST_LOG.md](docs/TEST_LOG.md)。

## 已知边界

- 完整 Xcode 27.2 已安装在外接盘，本项目构建脚本会自动使用它；macOS 27.2 SDK 已安装。
- 当前构建已使用本机 Apple Development 证书签名，辅助功能、输入监控和键盘事件过滤器均实测成功。
- “系统设置里已勾选”不等于实际生效；权限页会同时显示 TCC 状态并提供“实际测试”按钮。
- 当前测试机只有单台内置显示器。代码按每块 `NSScreen` 建立独立窗口，最终发布前仍需在双屏和三屏真机上回归。
- 当前 DMG 使用 Apple Development 签名，适合本机与个人测试，不能直接作为面向公众的 Developer ID 公证发行包。
